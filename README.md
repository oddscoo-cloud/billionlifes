# Billionlifes

Браузерный симулятор жизни. Имя и пол выбирает игрок, стартовые обстоятельства выпадают случайно. Дальнейшая жизнь складывается из решений, ограничений и случайных событий. После смерти открывается сводка прожитой жизни.

## Локальный запуск

Установите Node.js 24 LTS. При использовании nvm команда `nvm use` выберет версию из `.nvmrc`.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Чтобы проверить типы, запустить тесты и собрать статические файлы:

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`. Она настроена для размещения под путём `/billionlifes/`.

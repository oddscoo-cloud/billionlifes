# Beyond Birth

Браузерный симулятор жизни. Имя и пол выбирает игрок, стартовые обстоятельства выпадают случайно. Дальнейшая жизнь складывается из решений, ограничений и случайных событий. После смерти открывается сводка прожитой жизни.

## Локальный запуск

Установите Node.js 24 LTS. При использовании nvm команда `nvm use` выберет версию из `.nvmrc`.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Чтобы проверить типы, запустить тесты и собрать статические файлы:

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`. Она настроена для размещения под путём `/billionlifes/`.

Начните новую жизнь или продолжите предыдущую с главного экрана. Сохранение записывается после
каждого подтверждённого хода в IndexedDB. Оно привязано к профилю браузера и адресу приложения,
включая порт, поэтому у `dev` и `preview` могут быть разные сохранения. Годовой ход останавливается
на обязательном решении или смерти. Для просмотра финальной сводки после обновления страницы
выберите «Открыть итог жизни».


В большинстве игровых месяцев в хронике появляется событие из окружения. Раскройте запись,
чтобы увидеть подробности и изменения показателей. В разделе «Круг общения» под показателями видны семья, знакомые
и общие воспоминания. «Дневник» хранит личные записи внутри текущего сохранения.

Автоход проживает месяцы до важного выбора, завершения жизни или ручной остановки.


Серьёзные события начинаются в школьном возрасте и зависят от жизненного этапа, работы, денег и
окружения. Они ставят игру на паузу. Некоторые последствия наступают через два месяца.
Характер описан чертами с объяснением их происхождения. Черты формируются из трудных решений
и накопленного опыта, а некоторые помогают в дальнейшем, например при поступлении или собеседовании.
Несколько потерь и длительный стресс могут привести к тревожному состоянию, депрессии или истощению.
Игра не ставит диагноз по одному событию: состояние зависит от накопленного напряжения и поддержки.
Обращение за помощью, разговор с близкими и снижение нагрузки запускают разные пути восстановления.

Братья и сёстры появляются в круге общения. Во взрослом возрасте после некоторых встреч
в разделе «Самочувствие» может появиться симпатия. Развитие отношений зависит от решений игрока.

## Публикация на GitHub Pages

1. Создайте на GitHub репозиторий с именем `billionlifes` и отправьте в него содержимое этого проекта.
2. Установите Node.js 24 LTS и проверьте локальную сборку:

   ```sh
   npm ci
   npm run build
   ```

3. В настройках репозитория откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
4. Файл `.github/workflows/deploy-pages.yml` уже выполняет `npm ci`, `npm run build` и публикует папку `dist/`. После первого запуска ссылка будет иметь вид:

`https://<ваш-логин>.github.io/billionlifes/`

Путь `/billionlifes/` уже задан в `vite.config.ts`, поэтому приложение корректно работает именно по адресу проекта, а не только на корне домена.

# Billionlifes

Репозиторий проекта: `oddscoo-cloud/billionlifes`.

## Продолжение в новом чате

Запрос «Продолжи выполнение» означает выполнить один следующий этап Billionlifes. Он включает проверки, коммиты, отправку ветки этапа и слияние в `main` через merge commit. Если пользователь указал другой объём работы, следуй его запросу.

1. Проверь рабочую копию и обнови сведения об `origin/main`. Сверь [журнал этапов](docs/PROGRESS.md) с историей Git. Если есть незавершённая ветка нужного этапа, проверь её коммиты и продолжи с имеющейся работы. Сохраняй чужие изменения.
2. Прочитай [спецификацию](docs/SPEC.md), [план](docs/PLAN.md) и общий блок и задание выбранного этапа в [промптах](docs/PROMPTS.md).
3. Работай в ветке этапа, указанной в плане. Новую ветку создавай от актуальной `main`. Сохраняй разделение между движком, данными, хранением и интерфейсом.
4. Запусти обязательные проверки этапа, `npm run typecheck`, `npm test`, `npm run build` и `git diff --check`. Запиши фактические результаты, ограничения и следующий этап в `docs/PROGRESS.md` в той же ветке. Сохрани осмысленные коммиты.
5. После успешных проверок синхронизируйся с `origin/main`, слей ветку через `git merge --no-ff` и отправь `main` и ветку этапа. Проверь удалённые ссылки и два родителя merge commit. Если отправка или слияние заблокированы, сообщи, что осталось локально и почему.
6. Сообщи результат, проверки и ссылку на merge commit. Остановись после одного этапа, если пользователь не поручил больше.

Следующий исполнитель должен иметь доступ к этому репозиторию. Для локального запуска и команд установки см. [README.md](README.md).
